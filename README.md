# Vocabulary Hub and Semantic Artifacts in Data Spaces — ESWC 2026

Slides for a presentation on the Vocabulary Hub and semantic artifacts in data spaces, given at the Semantic Data Spaces (SDS) Workshop at ESWC 2026.

The presentation discusses the role of semantic artifacts in interoperable data spaces and introduces the Vocabulary Hub as an approach for publishing, discovering, and reusing the vocabularies, profiles, mappings, and other semantic resources required to interpret and integrate heterogeneous data.

The work explores how these artifacts can be made discoverable and actionable as part of data-space infrastructure, supporting semantic interoperability between independently published datasets and services.
